Course Description

Web Page Design teaches students how to plan, design, and build accessible websites using HTML, CSS, and introductory JavaScript. Learners practice user-centered design by creating responsive layouts that work on multiple devices.

Students explore branding, typography, and visual hierarchy while using wireframing tools to organize content. Projects include personal portfolios, community awareness sites, and client-based collaborations.

By the end of the course, each student launches a polished website hosted online and documents their process in a design case study.

Frequently Asked Questions

Do we need prior design experience?

No. The course introduces design fundamentals and provides templates to support beginners.

Will we learn coding?

Yes. Students write semantic HTML, craft CSS layouts, and use introductory JavaScript to add interactivity.

Can we build sites for real clients?

Students may partner with clubs or community organizations to develop live websites with instructor approval.
