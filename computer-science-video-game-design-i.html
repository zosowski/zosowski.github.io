Course Description

Video Game Design I introduces students to the fundamentals of interactive storytelling, game mechanics, and level design. Learners explore the design process from concept art to playable prototypes using beginner-friendly engines.

Students collaborate in teams to create 2D games, practice playtesting, and iterate on feedback. Topics include character design, user interface principles, and introductory programming concepts.

The course builds creative problem-solving skills and sets the stage for more advanced development experiences in Video Game Design II.

Frequently Asked Questions

Do I need to know how to code?

No coding experience is required. The course uses visual scripting and step-by-step tutorials to build programming confidence.

What software will we use?

Students experiment with engines such as Construct, Unity, or GameMaker depending on project goals.

Can I work on my own game idea?

Yes. Individual and team projects are encouraged, with checkpoints to ensure scope remains manageable.
